# QBoa Digital

Site oficial da QBoa Digital, com os downloads das versões para Windows.

## Downloads

- [QBoa Digital 1.0 BAT](download/qboa-digital-1.0.zip): limpeza simples.
- [QBoa Digital 2.0 BAT](download/qboa-digital-2.0.zip): otimização simples.
- [QBoa Digital 3.0 alpha9](download/qboa-digital-3.0-alpha9.zip): versão em breve.

As versões 1.0 e 2.0 são scripts BAT mais simples para executar as rotinas
principais. A versão 3.0 alpha9 está disponível para download, mas permanece
marcada como "Em breve" no site.
